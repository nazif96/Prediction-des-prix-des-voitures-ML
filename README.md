# Prediction-des-prix-des-voitures-

## 1- collecte de données 
**Web Scraping** de données de prix et caractéristiques des véhicules depuis `AutoScout24.com` pour avoir un dataset structuré avec des variables clés (marque, année, kilométrage, motorisation, etc.)

## 2- Analyse et modélisation.
- Analyse exploratoire des données puis Développement et comparaison de plusieurs modèles de machine learning (Random Forest, XGBoost,
Lasso Regression) pour prédire le prix des voitures.
- Optimisation du modèle avec une meilleure gestion des variables catégorielles et des techniques de
feature engineering
## Résultat : Modèle capable d'estimer les prix avec une précision de 85%.
